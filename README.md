# 영차마을 (구 Brain Village)

고령자 대상 **동작 기반 2인 협동 인지훈련** 웹게임 데모. 마을에서 미니게임을 골라 플레이한다.
데모 수록 게임: **오락가락 청기백기**, 게임 B **캠프파이어**, 게임 C **쿵떡쿵떡 떡방아**.

게임 C는 마을 지도에서 병원 왼쪽의 달 간판 건물 **보름달 떡집**을 눌러 진입한다. Figma 기반 화면 흐름, 받은 에셋 34개, 동작 규칙 및 검증 범위는 [게임 C 구현 기록](docs/game-c-figma-inventory.md)에 정리했다.

## 실행

```bash
npm install
npm run dev     # http://localhost:5199
npm run build   # dist/ 산출
```

인터넷 연결 없이 구동된다 (MediaPipe 모델·wasm·폰트·에셋 전부 로컬 포함).

## 스택

- Vite + React + TypeScript
- MediaPipe Tasks `PoseLandmarker` (lite, GPU delegate) — 프레임 좌/우 분할로 2인 동시 인식
- 구령 음성: 녹음된 낱말 클립을 Web Audio로 이어붙여 생성 (TTS 미사용)
- 에셋: 피그마 디자인 파일에서 MCP로 추출 (`public/assets/`, 크롭 매니페스트는 `src/assets.ts`)

## 플로우

기관 로그인 → 개인 로그인 → 메인 → 마을 → 게임별 준비·캐릭터 선택·연습 → 본게임 → 결과.

게임 C: 위치 잡기 → 손 내려놓기 → 높이 보정 → 토끼 선택 → 연습 → 본게임 2라운드(중간 역할 교대) → 완성 시 두 사람 양팔 들기 → 결과.

결과 화면 버튼: **다시하기** = 같은 팀이 바로 한 번 더(연습 생략) / **확인** = 마을로 / **홈으로** = 타이틀(다음 팀)

## 수행 데이터 전송

게임 A는 `cp .env.example .env` 후 실값을 채우면 구령 판정마다 Supabase로 올라간다. `.env`가 없으면 전송이 꺼지고 게임은 그대로 돌아간다. 게임 C는 현재 로컬 결과 및 JSON 다운로드를 제공하며 서버 전송은 아직 연결하지 않았다.

- `VITE_SITE_CODE`는 **서버 `site` 테이블에 등록된 코드**여야 한다. 아니면 세션 종료가 409로 조용히 실패해 팀 점수·완주 여부가 유실된다 ([demo-spec.md](docs/demo-spec.md) §25.2)
- Supabase 쪽 작업 요청(개인 리포트용 뷰·참가자 로스터 등): [docs/supabase-요청_개인리포트_20260826.md](docs/supabase-요청_개인리포트_20260826.md)
- 잘 갔는지 확인: 콘솔에 `[telemetry]` 경고가 없고, `performance` 리소스에 `session`/`trial`/`motion_window`/`rpc/close_session` 요청이 보이면 정상

## 운영(부스) 참고

- 진행요원 예비 키: **1P = Q(왼손)/W(오른손), 2P = O/P** — 홀드가 손들기로 인식됨
- 진행요원 단축키: **1** = 튜토리얼 단계·연습 구령 건너뛰기 / **2** = 결과 화면으로 이동(두 번 눌러야 실행)
- 카메라 사용 불가 시 자동으로 키보드 모드 전환
- 게임 C의 잼잼은 **1P E / 2P I**를 눌렀다 놓기 3회. 양손 들기·내리기는 Q/W 또는 O/P를 함께 눌렀다 놓는다. 카메라가 있어도 게임 C의 입력 안내에서 키보드 모드를 선택할 수 있다.
- 튜토리얼 각 단계 우하단 **건너뛰기** 버튼 (반투명)
- 로그인: 기관(이메일+비밀번호, 기기에 유지) → 개인(두 자리 번호 ×2). 타이틀 좌상단에 로그아웃 2개
- 진행요원 테스트 계정: `sonephmo` / `6875` (서버 미경유 로컬 우회, 기관 코드는 `.env` 기본값)
- 판정 규칙·채점·로그 스키마: [docs/demo-spec.md](docs/demo-spec.md) 참고 (v2.9)
