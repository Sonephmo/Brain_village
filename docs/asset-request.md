## 좌표 기준

원본 스프라이트 시트 기준입니다. 두 시트 모두 동일 구조입니다.

```
시트 크기: 1536 x 1024
격자:      4열 x 2행,  셀 크기 384 x 512

        ① 양손내림    ② 양손올림    ③ 화면왼팔    ④ 화면오른팔
행0     할머니
행1     할아버지
```

아래 좌표는 모두 **각 셀의 왼쪽 위를 (0,0)으로 한 셀 내부 좌표**입니다.

## 요청 1 — 포즈별로 머리가 좌우로 움직입니다 (중요)

기획 스펙 §5.3은 *"4개 포즈 모두 머리 위치·크기를 동일하게 유지"* 를 요구합니다. 표정이 별도 레이어로 얹히기 때문입니다. 실측 결과 **세로 위치와 크기는 잘 맞아 있고, 가로 위치만 어긋납니다.**

### 현재 상태 — 얼굴 중심 x

| 캐릭터 | ① 양손내림 | ② 양손올림 | ③ 화면왼팔 | ④ 화면오른팔 | 최대 편차 |
|---|---|---|---|---|---|
| 할머니 | **203** | 177 | 178 | **142** | 61px |
| 할아버지 | **203.5** | 177.5 | 180.5 | **145** | 58.5px |

②③번 칸은 이미 서로 맞아 있습니다. **①번과 ④번 칸만 어긋납니다.**

### 요청 — ①번과 ④번만 가로로 이동

②③번 칸은 그대로 두고, 나머지 두 칸의 **인물 전체를 통째로 가로 이동**해 주세요. 그림을 다시 그릴 필요는 없습니다.

| 캐릭터 | 칸 | 이동 | 결과 얼굴 중심 x |
|---|---|---|---|
| 할머니 | ① 양손내림 | **왼쪽으로 25px** | 178 |
| 할머니 | ④ 화면오른팔 | **오른쪽으로 36px** | 178 |
| 할아버지 | ① 양손내림 | **왼쪽으로 24px** | 180 |
| 할아버지 | ④ 화면오른팔 | **오른쪽으로 35px** | 180 |

이동해도 인물이 셀을 벗어나지 않는 것을 확인했습니다(가장 빡빡한 케이스가 할머니 ④번: 이동 후 x 36~339, 셀 폭 384 안에 들어옵니다).

### 이미 잘 맞아 있는 것 (수정 불필요)

- **얼굴 크기**: 할머니 109~111px, 할아버지 115~116px — 편차 2px 이내
- **얼굴 중심 y**: 할머니 211~213.5, 할아버지 158~158.5 — 편차 2.5px 이내

## 요청 2 — 두 캐릭터의 발 높이가 다릅니다

게임에서 두 사람이 **같은 운동장에 나란히 서 있는** 화면인데, 셀 안에서 발끝 높이가 다릅니다. 같은 크기 박스에 넣으면 할아버지가 공중에 떠 보입니다.

| 캐릭터 | 발끝 y (4개 포즈 모두 동일) |
|---|---|
| 할머니 | 452 |
| 할아버지 | **413** |

**차이 39px.** 각 캐릭터 안에서는 4개 포즈가 일정하게 맞아 있어서, 캐릭터 하나만 옮기면 됩니다.

### 요청

할아버지 4개 칸의 **인물 전체를 아래로 39px 이동**해서 발끝을 y=452 (셀 하단에서 60px 위)에 맞춰 주세요. 이동 후 인물 상단이 y=92라 셀 안에 들어옵니다.

> 할머니를 위로 올리는 방향도 상관없습니다. **두 캐릭터의 발끝 y가 같기만 하면** 됩니다.

## 확인 방법

수정본을 주시면 같은 방식(캔버스 알파/피부색 분석)으로 재측정해서 아래를 확인하겠습니다.

- [ ] 캐릭터별로 4개 포즈의 얼굴 중심 x 편차 **5px 이내**
- [ ] 두 캐릭터의 발끝 y 편차 **5px 이내**
- [ ] 인물이 셀(384×512) 경계를 넘지 않음

## 수정하지 않는 경우

지금 빌드는 **포즈별 앵커 8개를 실측해 코드에서 보정**해 두었으므로 화면상으로는 이미 정상입니다. 그대로 가도 데모는 문제없습니다.

수정을 요청하는 이유는 유지보수입니다.

| | 수정하면 | 수정 안 하면 |
|---|---|---|
| 코드 앵커 표 | 캐릭터별 1개 (총 2개) | 포즈별 8개 유지 |
| 포즈·캐릭터 추가 시 | 좌표 그대로 재사용 | 추가분마다 재측정 필요 |
| 발 높이 | 박스만 맞추면 정렬됨 | 캐릭터별 보정값 필요 |

정식 버전에서 미니게임과 포즈가 늘어날 예정이라면 지금 잡아두는 편이 낫습니다.
