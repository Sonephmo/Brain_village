Figma의 투명 원본과 실제 표시 좌표를 연결해 기존 민트 배경 내보내기 문제를 해결했다.

## 현재 적용 — 사용자 선택 임시 캐릭터

- 버전: `selected-temporary-20260930`. 사용자 첨부 정면을 기준으로 남녀 에셋을 동기화했다.
- 남자 정면 `male-profile-selected.png`는 사용자 첨부 파일과 SHA-256이 일치하는 원본 복사본이다. 여자 정면은 같은 시기의 `female-profile-v3.png`를 재사용한다.
- 남녀 `*-jamjam-sheet-selected.png`는 각각 3동작을 한 장에 생성했다. 정면 2장은 1448×1086, 동작 시트 2장은 2172×724. 4장 모두 RGBA, 투명도 범위 0~255, 디코딩 정상.
- 코드 `shopperFrame()`과 미리보기 `characters.html`은 `frames-active.json`을 공통으로 사용한다. 총 8프레임의 표시 영역이 이미지 범위 안에 있고 캐릭터 외곽이 잘리지 않는지 확인했다.
- 원본 PNG와 알파는 변경하지 않았다. 화면 표시 좌표로 발 위치를 맞췄으며, 각 캐릭터의 3동작 사이 발 중심 편차는 0.5px 이하이고 발바닥 높이는 같다.
- 브라우저에서 선택한 정면·동작 시트 로드 및 표시 확인, 콘솔 오류/경고 없음. TypeScript 검사 통과.
- 생성 방식: built-in imagegen. 원본 출처·저장 위치·최종 프롬프트: `character-temporary-selection.json`. 검토 화면: `characters.html`, 스크린샷: `character-review-selected.png`.
- 아래 revision 5 및 개별 8장 버전은 이전 기록이다. 파일을 보존하되 현재 코드와 미리보기에서는 사용하지 않는다.

2026-09-30. 이번 확인은 캐릭터 에셋 연결에 한정하며, 장보기 게임 로직 및 전체 누락 에셋 검토는 아직 완료하지 않았다.

- 당시 사용: `portraits-v5.png` (1536×1024 정면 2인), `male-jamjam-sheet-v5.png`와 `female-jamjam-sheet-v5.png` (각 2172×724, 3동작).
- 당시 `frames-v5.json`과 `shopperFrame()`을 통해 시트를 직접 표시했다. 원본 이미지는 잘라서 다시 저장하거나 알파를 변경하지 않았다.
- 프레임별 발 중심을 표시 좌표로 맞춤. 3동작 사이 좌우 편차 남자 1px, 여자 0.5px 이하(원본 기준), 발바닥 높이 동일.
- 브라우저에서 새 정면과 시트 재생 확인, 이미지 로드 오류 없음. TypeScript 검사 통과.
- 생성 방식과 최종 프롬프트: `character-revision-5.json`. 스크린샷: `character-review-v5.png`.
- 아래 내용은 그보다 이전 개별 8장 버전의 기록이다. 이전 파일은 비교용으로 남아 있으며 현재 미리보기/프레임 정의에서는 사용하지 않는다.
