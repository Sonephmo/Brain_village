# 협동 장보기 구현 및 확인 — 2026-09-30

## 적용 규칙

사용자 답변으로 확정한 규칙:
- 제한 시간 120초. 목록의 모든 수량을 채우면 즉시 성공으로 종료한다.
- 목록 밖 상품과 이미 채운 상품을 담으면 오답만 기록한다. 공동 바구니 수량은 바뀌지 않는다.
- 양팔을 앞으로 뻗고 양손을 편 상태에서 시작한다. 양손을 쥐는 순간 1회 담는다.
- 계속 쥐고 있어도 반복해서 담기지 않는다. 다음 담기 전 양손을 다시 펴야 한다.
- 손이 사라지거나 입력 모드를 바꾸면 진행 중인 동작을 초기화한다. 다시 양손을 펴서 준비한다.

Figma 원본: `CBa2GjaZh7Mn2fLDupSY32`, 규칙 `361:3, 361:6, 361:9, 361:12`, 플레이 `400:2`, 에셋 `393:14`.
시안의 60초는 사용자 답변에 따라 120초로 변경했다. 토끼는 사용자가 선택한 임시 츄리닝 캐릭터로 교체했다.

## 연결한 흐름

마을의 마트 → 위치·스트레칭·캐릭터 선택 → 난이도 선택 → 양쪽 잼잼 2회씩 연습 → 3초 카운트다운 → 본게임 → 결과.
결과에서 다시하기는 캐릭터 선택·연습을 생략하고 난이도를 다시 고를 수 있다.

- 좌우 컨베이어와 초록색 담기 영역, 공동 쇼핑 목록, 상품 이름·그림, 수량 합산.
- 왼쪽 전용 7종 / 오른쪽 전용 7종 / 공통 14종. 양쪽 공통 상품은 한 목록 수량을 공유한다.
- 목록에 없는 물건, 이미 완료한 물건, 빈칸에서 담기를 각각 기록한다.
- 정확도는 정답 담기 / (정답 담기 + 오답 담기 + 빈칸 동작). 시도 0회는 ‘—’로 표시한다.
- 놓침은 아직 필요한 상품이 담기 영역을 지나간 횟수다. 동일 물건이 다시 나타날 수 있어 목표 수량보다 많을 수 있다.
- 반응시간은 상품 중심이 초록 영역에 진입한 시점부터 정답 담기까지의 시간이다.
- 참가자별 정답·오답·빈칸·놓침·평균 반응·기여 비율, 최종 목록, 종료 사유를 표시한다.
- 중단 결과 및 JSON 다운로드. 기존 서버에 정의되지 않은 장보기 전송 형식은 임의로 만들지 않았다.

## 조정 가능한 구현값

규칙 문서의 범위 안에서 초기값을 선택했다. 이 값들은 사용자에게 확정받은 규칙과 구분한다.

| 난이도 | 목록 종류 | 종류별 수량 | 속도 (1920×1080 기준 px/s) |
| --- | --- | --- | --- |
| 쉬움 | 3 | 2–3 | 85 |
| 보통 | 5 | 2–4 | 100 |
| 어려움 | 7 | 3–5 | 115 |

상품 중심 간격 280px, 담기 영역 Y=844–1053. 어려울수록 방해 상품 빈도가 높다.
남은 목표 상품을 우선 공급해 무작위 선택 때문에 목록이 불가능해지는 상황을 막는다.
손 자세는 90ms 안정 구간으로 잡음을 거른다. 카메라 샘플은 약 100ms 간격, 400ms 이상 오래된 관측은 무효다.

## 입력과 화면 수명

- 장보기 전용 4손 인식 모델이 한 프레임의 손을 거울 화면상 왼쪽/오른쪽 참가자로 분리한다.
- 화면 중앙 경계의 손은 어느 참가자에게도 배정하지 않는다. 각 참가자의 두 손이 모두 주먹이어야 한다.
- 메뉴 클릭용 인식과 분리되어 게임 동작이 메뉴를 누르지 않는다.
- 키보드 예비 입력: 왼쪽 E / 오른쪽 I. 길게 누름·키 반복은 중복 동작이 아니다. 화면 버튼도 같은 판정 경로를 쓴다.
- Esc 또는 일시정지 버튼으로 시간·컨베이어·판정을 멈춘다. 탭을 숨기거나 창 포커스가 사라져도 멈춘다.
- 화면 종료 시 타이머와 이벤트를 해제한다. 다시하기는 새로운 목록과 기록으로 시작한다.
