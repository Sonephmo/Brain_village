기준: `5cc67a1` 이후 로컬 수정. 앞선 검토의 재현 결함 8건을 수정했다. 새 게임 추가, 서버 스키마 변경, 배포는 하지 않았다.

카메라 표본이 400ms 이상 갱신되지 않으면 A/B의 현재 입력으로 사용하지 않는다. 이 기준과 손목 가림에 따른 `누락` 판정은 실제 부스의 조명·성능·참가자 움직임으로 확인해야 한다.

## 기록 복구 방식과 제한

- 기존 `bv.telemetry.queue.v1` 저장소를 유지한다. 저장·전송 항목에 큐 ID를 붙이며 기존 데이터는 지우지 않는다.
- 네트워크 실패, HTTP 408/425/429/5xx는 큐에 남겨 다시 보낸다.
- 영구 거부 응답은 원문과 이유를 `bv.telemetry.rejected.v1`에 보존한다. 운영 확인 대상이며 서버 저장 성공을 뜻하지 않는다.
- `close_session=false`는 기존 서버 계약상 ‘대상 없음’과 ‘이미 종료’를 구분하지 못한다. 최대 3회 시도 후 원문을 별도 보존해 다음 세션 전송을 막지 않는다. 최종 상태 대조에는 서버 확인이 필요하다.
- 저장 공간이 부족하면 현재 탭의 메모리에 보존한다. 메모리에만 남은 기록은 탭을 닫으면 유지되지 않는다.
- 이번 검증은 한 게임 탭의 요청 순서와 복구를 대상으로 했다. 여러 탭의 동시 플레이와 실제 Supabase/RLS/리포트 집계는 검증하지 않았다.

## 에셋 검토

**실제로 쓰는 경로 156개에서 누락·대소문자 오류·배포 복사 누락은 없었다.** 매니페스트뿐 아니라 아바타/표정/토끼의 동적 경로와 실제 음원 로더가 만드는 URL까지 확인했다.

| 대상 | 수량 | 확인 |
|---|---:|---|
| 이미지 | 127 | 파일 존재·정확한 대소문자·브라우저 디코딩 통과 |
| 음원 | 20 | 파일 존재·브라우저 메타데이터 및 유효한 길이 확인. 실제 청취 품질 검사는 아님 |
| 글꼴 | 1 | 파일 및 브라우저 로드 통과 |
| MediaPipe 모델 | 2 | 파일·모델 패키지 시그니처·배포 복사 확인 |
| MediaPipe JS/WASM | 6 | 설치된 0.10.35 패키지와 일치. JS 줄바꿈 차이는 제외 |
| 스프라이트 자르기 영역 | 18 | 선언한 시트 크기와 자르기 범위 확인 |

브라우저에서는 미디어 148개(이미지 127 + 음원 20 + 글꼴 1)가 전부 열렸다. 깨진 이미지 0건이었다.

### 정리할 에셋

1. `public/assets/game_bg.png`와 `public/assets/game-b/result-background.png`는 확장자가 PNG지만 실제 내용은 JPEG다. 브라우저에서 정상 디코딩된다. 이번에는 원본과 경로를 변경하지 않고 파일명 정리 대상으로 기록했다.
2. 미사용 후보 10개는 구형 로고/마을 이미지, 원본 커서, B 표정, 오프닝 BGM 및 연결되지 않은 안내 음성이다. 원본이나 예비 자료일 수 있어 삭제하지 않았다. 목록은 JSON 보고서에 있다.
3. **콘텐츠 보완:** A의 ‘왼손’ 전용 연습 안내 녹음이 없다. 기존 ‘한손’ 음성은 문구가 달라 연결되지 않았다. B/C 전용 동작 안내 음성도 현재 로더와 게임 흐름에 없다. 이는 연결된 파일이 사라진 경우와 구분해야 한다.
4. 최신 Figma 전체와 1:1 대조한 검토는 아니다. 현재 저장소의 실행 경로와 파일 상태를 대상으로 했다.

## 검증 방법

- `npm test`: 이번 결함의 회귀 검사 9그룹과 기존 게임 C 동작·점수 검사 통과.
- `npm run typecheck`: 통과.
- `npm run build`: 프로덕션 빌드 통과.
- `npm run audit:assets`: 오류 0, 형식/확장자 경고 2. 먼저 빌드한 뒤 실행한다.
- 브라우저: 운영자 준비·연습 경로, A 20구령 결과·다시하기·중단, B 본게임 60초/10이벤트 결과, 변경 안내 문구와 깨진 이미지 여부 확인. A 결과 화면에서 20점·0/20 성공을 관찰했다. 실제 두 사람이 의도한 동작을 수행하는 환경은 아니며 미인식 정책은 별도 격리 입력 검사로 검증했다.

정상 동작 검사는 [test-game-regressions.mjs](../scripts/test-game-regressions.mjs)에 있다. 이전 [review-games-20260929.mjs](../scripts/review-games-20260929.mjs)는 `5cc67a1`의 결함을 재현하는 역사 자료이므로 수정된 소스에서는 실패하는 것이 예상된다. 현재 검증은 `npm test`를 사용한다.
