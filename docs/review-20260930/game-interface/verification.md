# 실제 장보기 연습과 게임 버튼 정리 — 2026-09-30

## 반영

- 장보기의 실제 컨베이어·물건·쇼핑 목록·캐릭터·바구니를 공통 장면으로 분리해 연습과 본게임에서 함께 사용한다.
- 연습은 각 참가자가 사과 두 개를 실제 담기 영역에서 집는다. 손을 쥐면 물건이 바구니로 이동하고, 목록 수량과 참가자별 횟수가 함께 증가한다. 다음 물건이 도착하기 전 입력은 인정하지 않는다.
- 연습 물건은 참가자를 기다린다. 연습 시간·물건 수량은 본게임 기록에 포함하지 않으며, 본게임은 새 목록과 120초로 시작한다.
- A/B/C/D의 상시 운영 버튼을 작은 공통 메뉴 하나로 정리했다. 일시정지 후 펼치는 진행자 설정 안에 입력 안내, 카메라 미리보기, 입력 방식, 장보기 난이도 등을 배치했다.
- 건너뛰기와 두 번 누르는 중단 단축키는 유지했다. 중단 대기 상태는 버튼 대신 안내 문구로 알린다.
- 준비 화면의 단계 건너뛰기, 결과 화면의 기록 다운로드는 펼침 메뉴 안으로 이동했다. 장보기의 화면 클릭용 잼잼 버튼은 제거하고 키보드 E/I 입력을 유지했다.
- 떡방아의 음성 상태 안내가 아래쪽 동작 설명을 가리지 않도록 위치를 조정했다.

## 확인

- `npm test`: 공통 회귀 11개 그룹, 떡방아 동작 테스트, 음성·화면 18개 그룹, 장보기 9개 그룹 통과.
- 추가 검증: 연습의 빠른 입력 거절, 참가자별 기다림, 초과 입력 거절, 바구니 수량 반영, 정지 중 컨베이어 위치 보존, 본게임 세션 분리.
- `npm run typecheck`, `npm run build`, `git diff --check` 통과.
- 에셋 검사: 참조 202개·프레임 59개, 누락 0건. 기존 JPEG 내용의 PNG 확장자 경고 2건 유지.
- 브라우저: 장보기 보통 난이도 설정 → 각 참가자 두 번 담기 → 4/4 완료 → 본게임 진입을 확인했다. 본게임 목록 5종과 선택한 난이도가 유지됐다.
- A/B/C/D 연습 화면의 상시 게임 버튼은 메뉴 하나로 정리됐다. 장보기의 준비·연습 완료 단계에서는 필요한 다음 버튼도 표시된다.
- 브라우저에서 공통 메뉴, 떡방아 입력 안내와 재개, 떡방아 건너뛰기 단축키, 준비 화면의 접힌 진행 메뉴를 확인했다. 검증 중 브라우저 오류·경고는 없었다.
- 실제 두 참가자의 카메라 인식은 이번 검증에서 사용하지 않았다. 브라우저 검증은 카메라를 요청하거나 기록을 전송하지 않는 로컬 점검 화면의 키보드 입력으로 진행했다.
