# 네 게임 빠른 검토 — 2026-09-30

후속 처리: 아래 1·2번은 수정 완료했다. 구현 내용과 재검증 결과는 [일시정지·기록 시각 수정](pause-and-timestamps.md)을 참고한다. 아래 내용은 수정 전 검토 기록이다.

대상: 안내 음성 연결까지 반영된 현재 로컬 작업본. 게임 코드는 수정하지 않았다.
이번 검토는 회귀 검사와 짧은 데스크톱 키보드 화면 확인이다. 실제 두 사람이 카메라 앞에서 진행하는 전체 플레이, 서버 왕복, 모바일/모션 감소 환경의 검증은 포함하지 않는다.

## 확인 범위

| 게임 | 자동 검사 | 이번 브라우저 확인 |
|---|---|---|
| 청기백기 | 20구령 정상 입력 100점, 유효 관측·유지시간·연습 음성·중단 정리 | 첫 연습 구령, 안내와 진행요원 버튼 |
| 불피우기 | 10구령, 음성 종료 후 6초 판정, 정지/부채질 판정·중단 정리 | 본게임 3번째 구령까지 진행, 시간·구령·동작 가능 안내 |
| 떡방아 | 20구령, 3초 판정, 잼잼·역할 교대·마무리·음성 | 본게임 6번째 구령까지 진행, 시간·구령·동작 가능 안내 |
| 장보기 | 재무장·오답·수량 합산·120초 종료·성공·음성·일시정지 | 규칙 → 시작 안내 → 카운트다운 → 본게임 → 일시정지 |

- `npm test` 통과: 공통 9그룹, 떡방아 동작 검사, 음성 13그룹, 장보기 8그룹.
- TypeScript 검사 통과.
- 현재 배포 산출물과 비교한 에셋 검사: 202개 경로 / 59개 프레임 / 오류 0개. 기존 PNG 확장자 JPEG 경고 2건 유지.
- 브라우저는 실제 게임 화면을 불러오는 로컬 점검 페이지를 사용했다. 로그인 및 서버 기록 전송은 수행하지 않았다. 이번 짧은 브라우저 확인에서 모든 게임의 완주·결과 화면을 다시 확인한 것은 아니다.

## 남아 있는 항목

1. **[P2] 기존 세 게임의 일시정지 부재.** A는 창이 가려져도 watchdog으로 진행하고, B/C는 동작 시간과 구령 전환을 멈추는 제어가 없다. 참가자가 쉬거나 운영자가 다른 창으로 이동해도 구령과 채점이 진행될 수 있다. D의 명시적 일시정지·창 전환 정지 동작과 통일을 권장한다. 코드 확인: `src/game/engine.ts:105`, `src/screens/GameBScreen.tsx:167`, `src/screens/GameCScreen.tsx:132`, 비교 `src/screens/GameDScreen.tsx:65`.

2. **[P2] 청기백기 내보내기의 시작시각이 실제 시작시각이 아님.** 동일한 결과로 `buildSessionLog()`를 두 번 호출하면 호출 시점에 따라 시작시각이 바뀐다. 결과를 늦게 내려받을수록 기록 시각도 밀린다. 실제 게임 시작 시각을 결과까지 전달해야 한다. 관련 서버 기록의 `onset_ts`도 현재 판정 완료 시점에 생성한다. 코드: `src/game/logging.ts:21`, `src/game/telemetry.ts:263`, `src/game/telemetry.ts:275`.

3. **불피우기 중단 결과의 등급 정책.** 한 동작만 성공한 미완주 결과에서 두 참가자 모두 불꽃 5/5가 표시되는 것을 현재 결과 컴포넌트로 재현했다. ‘1번 중 1번 성공’, ‘중단 전 완료한 동작 기준’은 표시되지만 완주와 같은 최고 등급으로 오해할 수 있다. 미완주에는 등급을 생략하거나 완주 평가와 분리하는 정책을 권장한다. 코드: `src/screens/GameBResultScreen.tsx:20`.

4. **B/C/D 누적 저장과 참가자 식별 연결 미완성.** 현재 A만 서버 기록 경로를 사용한다. B/C/D는 화면 결과와 JSON 내보내기를 제공하지만 기관·참가자 코드·공통 세션 ID가 결과에 포함되지 않는다. 개인별 누적 리포트가 필요하다면 별도 연결이 필요하다. 관련 파일: `src/screens/GameBResultScreen.tsx`, `src/screens/GameCResultScreen.tsx`, `src/screens/GameDResultScreen.tsx`. 이는 새 음성 연결로 생긴 오류가 아니라 기존 구현 범위의 차이다.

불피우기 등급과 청기백기 시각 문제의 격리 재현: [remaining-issues.json](remaining-issues.json). 재현 과정에서는 실제 서버를 호출하지 않았다.

권장 순서: 기존 세 게임 일시정지 통일 → 청기백기 기록 시각 수정 → 중단 결과 표시 정책 정리 → 서버 누적 저장 연결. 실제 2인 카메라 시험은 별도로 필요하다.
