# 장보기 튜토리얼 통일 — 2026-09-30

기존 청기백기·불피우기·떡방아 튜토리얼을 참고해 장보기의 팝업형 안내를 전체 화면 안내로 바꿨다.

## 반영 내용

- 공통 밝은 배경, 큰 제목과 동작 안내, 큰 참가자 캐릭터 배치를 적용했다. 임시 캐릭터 에셋 자체는 유지했다.
- 쇼핑 목록 예시와 난이도 선택을 준비 화면에 배치하고, 자세한 입력 안내는 펼쳐볼 수 있게 했다.
- 연습 화면은 참가자별 `0 / 2` 진행도, 완료 시 기존 `Good` 효과, 양손 준비 안내를 표시한다.
- 기존 게임의 `3 → 2 → 1 → 시작` 이미지와 표시 시점을 사용한다. 카운트다운이 끝난 뒤 120초 본게임을 시작한다.
- 음성 안내 중 입력 차단, 양손 다시 펴기, 두 사람 각각 두 번 연습, 일시정지 및 난이도 선택을 유지했다. 운영자용 연습 건너뛰기 `1`도 지원한다.

## 확인

- `npm test`: 공통 회귀 11개 그룹, 떡방아 테스트, 음성·화면 18개 그룹, 장보기 8개 그룹 통과.
- `npm run typecheck`, `npm run build`, `git diff --check` 통과.
- `npm run audit:assets`: 참조 202개·프레임 59개, 누락 0건. 기존 JPEG 내용의 PNG 확장자 경고 2건은 그대로다.
- 브라우저에서 보통 난이도 선택 → 안내 음성 → 양쪽 참가자 각 2회 연습 → 완료 표시 → 시작 안내 → 본게임 진입을 확인했다. 본게임 목록은 보통 난이도의 5종을 유지했다.
- 연습 화면에서 이미지 누락 0개, 버튼·제목·안내 문구의 화면 영역 이탈 0개를 확인했다.
- 카운트다운 중 일시정지와 재개, 음성 종료 전 입력 차단, 정지 중 건너뛰기 차단은 자동 테스트로 확인했다.
- 실제 두 사람의 카메라 동작 인식은 이번 UI 확인 범위에 포함하지 않았다.
