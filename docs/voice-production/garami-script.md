## 생성 및 연결 시 확인할 점

- 문장별 개별 더빙으로 생성·내려받아 위 파일명과 대응시킨다. 기존 음원의 파일이나 설정은 덮어쓰지 않는다.
- 동일 보이스/설정으로 한두 문장을 먼저 들어보고 기존 녹음과 비교한다. 내려받은 원본은 보존한다.
- B 연습은 다섯 번, 본게임은 두 번이다. 안내 음성을 서로 바꿔 연결하지 않는다.
- C 연습 설명과 본게임 구령을 분리했다. 음성 종료 뒤 3초 반응 창을 열고, 반응 속도도 그 시점부터 계산한다.
- C 마무리 음성은 실제 마무리 동작 단계에서만 재생한다. 낮은 점수 결과에는 해당 단계를 강제로 추가하지 않는다.
- 제작 상태: **21개 문장 생성·저장 완료 / 로컬 원본 확보 및 파일명 정리 완료 / 브라우저 디코딩 검사 21개 통과 / 게임 연결 완료**.
- MP3 21개를 끝까지 디코딩해 유효한 길이와 비무음 샘플을 확인했다. 모두 모노 음원이며, 검사 시 24,000Hz로 디코딩했다. 첫 문장 `a_practice_left.mp3`는 실제 플레이어에서 2.39초 끝까지 오류 없이 재생 완료된 것을 확인했다. 이는 파일·재생 데이터 검사이며, 전체 발음에 대한 사람의 청음 평가나 기존 녹음과의 비교를 대신하지 않는다.
- 본게임 C 구령 길이: 방아찧기 **1.85초**, 주무르기 **2.20초**, 왼쪽 **2.28초**, 오른쪽 **2.32초**. 안내 종료 뒤 반응 창이 열리는 것을 자동 검사와 브라우저에서 확인했다. B 왼쪽·오른쪽 연습 설명은 각각 **6.23초·6.41초**이며, 설명이 끝나기 전의 동작은 세지 않는다.
- 웹 편집기에 저장된 21개 문장과 보이스를 `clova-project-verification.json`에 기록했다. 첫 문장에 임시로 적용됐던 기본 보이스 아라는 가람으로 변경됐으며, 최종 21개 모두 가람으로 확인했다.
- 초기 자동 다운로드에서는 로컬 경로를 확인하지 못했으나, 이후 사용자가 `Downloads/영차마을_가람이_안내음성_20260929/`의 01~21번 파일을 제공했다. 현재는 모든 원본을 확보했으며, 원래 다운로드 파일은 그대로 두었다.
- 다운로드 화면에는 무료 채널 게시 및 CLOVA Dubbing 출처 표기 조건, 상업적 사용 시 NAVER CLOUD CLOVA Dubbing 이용 안내가 표시됐다. 배포 용도의 이용 범위는 별도로 확인해야 한다. 유료 플랜 신청이나 결제는 하지 않았다.

클로바더빙은 개별 더빙 다운로드를 제공한다. 참고: [공식 프로젝트 제작 안내](https://guide.ncloud-docs.com/docs/clovadubbing-project).
