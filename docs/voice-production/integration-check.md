# 안내 음성 연결 검증 — 2026-09-30

후속 작업: 떡방아 기본자세 음성 및 장보기 가람 음성 10종을 추가 연결했다. 최신 에셋 검사 202개, 오류 0개. [후속 연결 기록](shopping-voice-integration.md). 아래는 앞선 21종 연결 시점의 기록이다.

가람 음성 21개를 게임의 안내 단계에 연결했다. 다운로드 원본과 프로젝트 음원은 그대로 보존하며, 새 음원은 자르기·속도·피치·음량 보정 없이 전체를 재생한다.

## 동작 변경

- 청기백기: 연습 5개는 문장 안내가 끝난 뒤 동작을 받는다. 기존 짧은 단어 구령과 긴 연습 설명이 겹치지 않는다. 누락됐던 왼손 문장도 연결했다. 본게임의 기존 구령과 2초 반응 창은 유지한다.
- 불피우기: 연습은 다섯 번, 본게임은 두 번에 맞는 음성을 각각 사용한다. 10개 본게임 구령마다 안내 종료 후 6초 동안 동작을 받는다. 표시된 60초는 동작 시간의 합이며, 안내 시간만큼 실제 플레이 시간은 늘어난다.
- 떡방아: 토끼 선택, 연습 4종, 본게임 4종, 역할 교대, 마무리에 음성을 연결했다. 20개 구령 각각 안내 종료 후 3초 반응 창과 1초 피드백을 사용한다. 표시된 80초에는 안내와 역할 교대 시간이 포함되지 않는다. 반응 속도 기록도 안내 종료 시점부터 계산한다.
- 역할 교대는 안내 종료와 기존 4초 표시 시간을 모두 충족한 뒤 진행한다. 50점 이상인 경우에만 기존 마무리 동작과 음성이 나온다. 안내 중 미리 올린 팔은 내려서 다시 들어야 마무리 동작으로 인정한다.
- 결과 안내는 세 게임의 결과 화면에서 공통으로 재생하며, 다시하기·마을·처음으로 이동할 때 취소한다.
- 연습 배경음악을 0.45에서 0.22로 낮췄다. 불피우기·떡방아에는 안내 중/동작 가능 상태를 화면에도 표시한다.

## 중단 및 실패 처리

단계가 바뀌거나 건너뛰기·중단·화면 종료를 하면 해당 안내, 콜백, 카운트다운을 정리한다. 먼저 끝난 화면의 늦은 로드가 다음 화면에서 재생되지 않는다. 로드 대기는 최대 4초이며, 음원 누락·자동재생 차단·오디오 API 미지원 시 문장을 읽을 시간을 확보한 뒤 동작을 받는다. 오디오 시계가 멈춘 경우에도 음원 길이 + 1.5초에 재생을 중지하고 대기를 끝낸다.

## 검증 결과

- `npm run typecheck`: 통과.
- `npm test`: 기존 게임 회귀 검사와 신규 음성 검사 9개 그룹 통과. 신규 검사는 실제 음성 모듈과 게임 화면 코드를 통제된 시간·입력 환경에서 실행한다.
- 신규 검사 범위: 실제 종료 이벤트, 최소 표시 시간, 취소·교체·늦은 로드, 음원/API/자동재생 실패, 정지한 오디오 시계, A 연습의 중복 구령 방지, B 전체 10개 구령, C 전체 20개 구령, 연습 입력 차단, 0점/100점 완료 및 마무리 동작, 반응 속도 기준 시각.
- `npm run build`: 통과. 새 음성은 배포 폴더에 포함된다.
- `npm run audit:assets`: 실제 참조 177개, 누락/오류 0개. 기존 PNG 확장자의 JPEG 이미지 2개 경고는 유지되며, 앞선 브라우저 검사에서 디코딩이 확인된 파일이다. 새 음성 21개가 모두 실제 참조 목록에 포함된다.
- 실제 브라우저: 제작용 게임 화면을 별도 로컬 점검 페이지에서 불러와 A 연습의 왼손 안내·건너뛰기, B 연습·본게임, C 준비·토끼 선택·연습·본게임·결과 음성 진입을 확인했다. 게임 로그인이나 서버 기록 전송, 실제 카메라 촬영은 하지 않았다.
- 브라우저 B 관찰 예: 107.63초에 동작 시작 → 113.66초 다음 안내, 116.41초 동작 시작 → 122.46초 다음 안내. 50ms 입력 폴링을 포함해 약 6초의 반응 시간을 보존했다.
- 브라우저 C 관찰 예: 8.90초 안내 시작 → 10.75초 동작 시작 → 13.75초 피드백. 다음 구령은 14.78초 안내 시작 → 16.98초 동작 시작 → 20.03초 피드백. [원본 전환 기록](browser-c-timing.txt).

실제 두 사람이 카메라 앞에서 수행하는 현장 검사, 전체 발음의 사람 청음 평가, 기존 녹음과의 음색·체감 음량 비교는 포함하지 않는다. Git 커밋·푸시·외부 배포는 하지 않았다.
