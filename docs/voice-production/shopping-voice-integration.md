## 게임에 연결한 방식

- 준비 화면에서 규칙 안내를 끝까지 들은 뒤 연습 버튼이 열린다.
- 연습 안내 중 움직임은 세지 않는다. 안내 종료 뒤 새로 손을 펴고 쥐어야 1회가 된다.
- 시작 안내 종료 → 3초 카운트다운 → 120초 본게임 순서다.
- 담기 피드백 음성은 본게임 시간을 멈추지 않는다. 동시에 한 문장만 재생하고, 시작 간격을 최소 6초로 제한한다. 양쪽 참가자의 화면 피드백과 채점은 각각 유지한다. 오래된 안내를 대기열에 쌓지 않는다.
- 일시정지 시 진행 중인 안내와 피드백을 취소한다. 재개 안내가 끝난 뒤 타이머와 동작 판정을 다시 시작한다.
- 성공·시간 종료 안내가 끝난 뒤 결과 화면으로 넘어간다. 공통 결과 안내와 겹치지 않는다.
- 화면 종료 시 음성과 대기 콜백을 정리한다. 음원 로드/자동재생 실패에도 기존 읽기 시간 대체 처리를 사용한다.
